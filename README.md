Documentation Assets (doc-assets)
=================================

Цей монорепозиторій призначений для зберігання та хостингу інтерактивних віджетів (HTML/CSS/JS), які використовуються як вбудовані елементи (iframes) у документації.

Мета проєкту --- забезпечити єдине, централізоване місце для керування візуальними та інтерактивними інструментами, що покращують технічну документацію.

📁 Структура проєкту
--------------------

Репозиторій організовано за принципом "одна папка --- один віджет".

```
doc-assets/
├── assets/                  # Спільні ресурси (глобальні стилі, іконки тощо)
├── widgets/                 # Папка, що містить усі ізольовані віджети
│   ├── widget-name-1/       # Кожен віджет живе у власній директорії
│   │   └── index.html       # Головний файл віджета
│   └── widget-name-2/
│       └── index.html
├── index.html               # Головна сторінка-каталог з переліком усіх віджетів
└── README.md

```

🚀 Як використовувати віджети
-----------------------------

Усі віджети хостяться через GitHub Pages. Щоб вбудувати віджет у платформу для документації (наприклад, через Iframe), використовуйте пряме посилання на директорію віджета.

**Формат посилання:** `https://<username>.github.io/doc-assets/widgets/<widget-name>/`

*Примітка: Оскільки головним файлом віджета завжди є `index.html`, вказувати його у URL не обов'язково.*

🛠️ Як додати новий віджет
--------------------------

Щоб додати новий інструмент до каталогу, виконайте наступні кроки:

1.  **Створіть директорію:** Створіть нову папку всередині `/widgets/` з описовою назвою (використовуйте кебаб-кейс, наприклад, `my-new-widget`).

2.  **Додайте код:** Розмістіть ваш HTML, CSS та JS код у файлі `index.html` всередині нової папки.

    -   *Рекомендація:* Намагайтеся тримати віджети максимально автономними (single-file), щоб спростити підтримку.

3.  **Оновіть каталог:** Додайте посилання на ваш новий віджет у список на головній сторінці `index.html` (у корені репозиторію). Це допоможе швидко знаходити необхідні інструменти.

4.  **Зробіть Commit & Push:** Відправте зміни до гілки `main`. GitHub Pages автоматично оновить сайт.

🔒 Безпека та конфіденційність
------------------------------

Цей репозиторій є публічним (для забезпечення роботи GitHub Pages). **Суворо заборонено** розміщувати у коді віджетів:

-   Внутрішні ключі API, токени доступу або паролі.

-   Конфіденційні дані користувачів або клієнтів.

-   Пропрієтарний код компанії, який не призначений для відкритого доступу.

-   Внутрішні посилання, IP-адреси або назви внутрішніх серверів.

Усі віджети повинні бути абстрактними, загальнотехнічними інструментами (калькулятори, схеми розпіновки, інтерактивні діаграми тощо).
